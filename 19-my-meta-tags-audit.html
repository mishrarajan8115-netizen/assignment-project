Meta Tag Audit

Essential metadata used in an HTML webpage.

Meta Tags Report

Essential HTML Meta Tags
Meta Tag Purpose
charset Defines character encoding.
viewport Helps pages fit mobile screens.
description Summarizes the webpage for search results.
author Identifies the page author.
robots Provides crawling and indexing instructions.
theme-color Suggests a browser interface colour.
Open Graph Provides information for social media previews.

Audit Checklist

  • Character encoding is declared.
  • Viewport metadata is included.
  • Page title and description are provided.
  • Author and robots metadata are included.
  • Open Graph tags are present.
